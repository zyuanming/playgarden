# Playgarden · 玩出一点新发现

一个模块化、组件化的开源浏览器益智游戏大厅。适合亲子一起玩，也欢迎成年人来挑战空间推理与编程思维。

**第一版有 3 个可玩的原创游戏、共 9 个关卡。** 不使用广告、账号、聊天、追踪脚本或排行榜。收藏与关卡进度仅保存在当前浏览器。

## 开始

需要 Node.js 22.12+（本项目在 Node.js 24 验证）。

```bash
npm ci
npm run dev
```

打开终端显示的本地地址。生产构建与检查：

```bash
npm run typecheck
npm test
npm run build
```

构建产物在 `dist/`，可交给任意静态托管服务。当前仓库不代表已经部署了线上网站。

## 游戏

| 游戏       | 学习主题           | 操作                                         |
| ---------- | ------------------ | -------------------------------------------- |
| 光线实验室 | 光的反射、空间推理 | 点击镜子切换方向，连接光源与星星             |
| 机器人路线 | 顺序、循环、调试   | 组合前进与转向指令，设置重复次数并运行       |
| 积木桥梁   | 空间旋转、连通性   | 点击俯视桥块旋转，实时查看 Three.js 三维桥面 |

每个游戏都有 3 关，支持暂停、重来、提示与撤销。所有操作可点击或通过 Tab + Enter/空格完成；Escape 暂停/继续。手机无需拖拽。游戏没有计时压力。积木桥梁的 WebGL 不可用时仍可以通过二维桥面游玩。

## 验证状态

- TypeScript 类型检查、Vite 生产构建、34 项自动化测试通过（19 项纯逻辑/存储测试 + 15 项 DOM 交互测试）。
- DOM 测试覆盖九个关卡的完整解法、收藏/搜索/难度筛选、进度持久化、暂停/恢复、重来和撤销。Three.js 预览在 DOM 测试中使用替身，不能据此证明 WebGL 渲染效果。
- **桌面与移动端真实浏览器交互、像素视觉和 WebGL 仍待验证。** 当前执行环境拒绝本地浏览器套接字，云浏览器也无法访问本地开发地址。响应式样式已经实现，但未宣称完成真实设备验收。
- GitHub Actions 仅运行检查和构建，不部署网站。

## 模块结构

```text
src/
  App.tsx                   大厅、搜索、筛选、收藏
  components/GameShell.tsx  通用关卡/暂停/重来/提示/撤销/通关外壳
  components/BridgeScene.tsx 可释放资源的 Three.js 预览
  games/*Logic.ts           无 UI 依赖的纯逻辑与关卡
  games/*.tsx               按需加载的独立游戏模块
  lib/registry.ts           游戏注册表
  lib/progress.ts           本地版本化进度与容错
  lib/types.ts              模块共享契约
```

模块按需加载。Three.js 只在进入积木桥梁时加载。基础大厅不需要 3D 引擎。

## 添加一个游戏

1. 在 `src/games/` 添加纯逻辑与对应测试。
2. 写一个默认导出的 React 组件，接受 `GameProps`。`paused` 时阻止输入并冻结计时；响应 `resetToken`、`hintToken`、`undoToken`；通过 `onStatus` 提供可读反馈，通过 `onComplete` 报告通关。
3. 在 `lib/types.ts` 的 `GameId`、进度初始值及校验器中加入 ID，再在 `registry.ts` 注册元数据和 `lazy` 导入。
4. 提供可访问的键盘/触屏操作、移动布局、断开或失效依赖的回退。
5. 新游戏发布前检查代码、音乐、字体、图片、商标和关卡内容的许可证；不能只看仓库许可证。

当前关卡外壳为三个关卡设计；后续将把关卡数量等能力提取到注册表中。新增游戏时应同时完善这部分契约，不能仅添加一个看似可点击的卡片。

## 隐私与无障碍

- 使用 `playgarden.progress.v1` 本地保存收藏、完成关卡和静音偏好；清除站点数据即可移除。
- 不收集儿童或成年用户的姓名、年龄、位置、联系方式或行为数据。
- 不加载远程字体、广告 SDK、分析 SDK 或第三方嵌入式游戏。
- 系统减少动态效果设置会禁用装饰过渡。通关提示音由浏览器合成，可随时静音；无外部音频下载。
- 颜色不是唯一状态提示，主要反馈也提供文本；按钮拥有键盘焦点样式。
- 浏览器禁止本地存储时可以正常玩，但进度不会跨刷新保留。
