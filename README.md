# Playgarden · 玩出一点新发现

一个模块化、组件化的开源浏览器益智游戏大厅。适合亲子一起玩，也欢迎成年人来挑战空间推理与编程思维。

**本批扩展到 41 款独立游戏、492 个关卡，长期目标为 100 款优秀游戏。** 不使用广告、账号、聊天、追踪脚本或排行榜。收藏与关卡进度仅保存在当前浏览器。

## 开始

需要 Node.js 22.12+（本项目在 Node.js 24 验证）。

```bash
npm ci
npm run dev
```

打开终端显示的本地地址。生产构建与检查：

```bash
npm run typecheck
npm test
npm run build
```

构建产物在 `dist/`，可交给任意静态托管服务。当前仓库不代表已经部署了线上网站。

## 验证状态

- TypeScript 类型检查、Vite 生产构建、1315 项本地逻辑/存储/DOM 自动化测试通过。每个关卡都有可复现的解法验证；数独验证唯一解，花园侦探验证不猜测推理，熄灯谜阵用 GF(2) 求解器验证。
- 浏览器测试覆盖 1536×1024 桌面窗口和 390×844 触屏模拟窗口。上一批 33 款/396 关已通过 68 个浏览器场景及截图复核。本批扩展为 84 个场景、完整执行全部 492 关；新增批次仍在等待浏览器验收，发布前以 GitHub Actions 实际结果为准。
- 浏览器测试发现并修复了机器人换关时旧动画帧导致的错误，并加入回归测试。DOM 测试另外覆盖重来、撤销与执行中暂停/恢复。
- 运行 `npx playwright install chromium` 后可用 `npm run test:e2e` 重现浏览器检查；完整结果和临时截图在 [GitHub Actions](https://github.com/zyuanming/playgarden/actions) 中查看。
- 尚未验证 Safari、Firefox、真实 iOS/Android 硬件、屏幕阅读器或完整 WCAG 合规性。手机尺寸的 Chromium 测试不等于真机验收。
- 全量依赖审计在 2026-10-04 报告 0 项漏洞；该结果是时间点检查，不是持续安全保证。
- CI 仅运行检查和构建，不部署网站。

## 模块结构

```text
src/
  App.tsx                   大厅、搜索、筛选、收藏
  components/GameShell.tsx  通用关卡/暂停/重来/提示/撤销/通关外壳
  components/BridgeScene.tsx 可释放资源的 Three.js 预览
  games/*Logic.ts           无 UI 依赖的纯逻辑与关卡
  games/*.tsx               按需加载的独立游戏模块
  lib/registry.ts           游戏注册表
  lib/progress.ts           本地版本化进度与容错
  lib/types.ts              模块共享契约
```

模块按需加载。Three.js 只在进入带三维场景的游戏时加载。基础大厅不需要 3D 引擎。

## 添加一个游戏

完整契约与发布门槛见 [新模块接入指南](docs/NEW_GAME_GUIDE.md)。

1. 在 `src/games/` 添加纯逻辑与对应测试。
2. 写一个默认导出的 React 组件，接受 `GameProps`。`paused` 时阻止输入并冻结计时；响应 `resetToken`、`hintToken`、`undoToken`；通过 `onStatus` 提供可读反馈，通过 `onComplete` 报告通关。
3. 在 `lib/catalog.ts` 的 `GAME_IDS` 加入稳定 ID，再在 `registry.ts` 注册轻量元数据、真实关卡数量、来源/许可证和 `lazy` 导入。不要在大厅入口急切加载关卡求解器。
4. 提供可访问的键盘/触屏操作、移动布局、断开或失效依赖的回退。
5. 新游戏发布前检查代码、音乐、字体、图片、商标和关卡内容的许可证；不能只看仓库许可证。

关卡数量由注册表驱动；关卡选择、继续未完成关卡、完成进度不再假设固定数量。目录超过 12 个项目时分批展示。已保存的 v1 进度会自动迁移到 v2；扩展关卡不会抹掉原来的成绩。

## 隐私与无障碍

- 使用 `playgarden.progress.v2` 本地保存收藏、完成关卡和静音偏好；清除站点数据即可移除。
- 不收集儿童或成年用户的姓名、年龄、位置、联系方式或行为数据。
- 不加载远程字体、广告 SDK、分析 SDK 或第三方嵌入式游戏。
- 系统减少动态效果设置会禁用装饰过渡。通关提示音由浏览器合成，可随时静音；无外部音频下载。
- 颜色不是唯一状态提示，主要反馈也提供文本；按钮拥有键盘焦点样式。
- 浏览器禁止本地存储时可以正常玩，但进度不会跨刷新保留。
