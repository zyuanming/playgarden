# 平衡雕塑

八个原创静力雕塑挑战，逐层水平摆放有限、定重、定尺寸的刚性积木。每关按蓝图顺序供给材料，所有积木必须用完，顶层几何中心必须达到标线。全部代码、数据、插画 GPL-3.0-only，无新增依赖。

## 真正的逐界面物理检查
对每个接触界面 k，计算 k 以上所有积木总质量及质量加权质心；支撑区是第 k 块与下块（首块为基台）的实际区间交集。所有界面都必须有正宽接触且合质心落入接触区。不是只检查单块的中心，更不是只看整塔重心。每次放置都会重新计算全部接口。

白线为每块自身质心，绿/红点为该承重接口上方全部积木的合质心。后两课有明确标注的非均匀密度配重块，其自身质心不同于外形中心。模型是竖直重力下的理想二维单列刚体，不模拟动态冲击、风、弹性或摩擦；质心刚好落在边缘算临界平衡，界面与文档明确披露。

这与已有 BalanceLab 的杆臂力矩配平、CloudStack 的定时重叠裁切完全不同：无杠杆枢轴、无定时、无宽度裁切，每个固定尺寸块保留其质量，放得太偏会使下层接口失稳。

八课：宽支撑入门、轻梁悬挑、重底座、细腰承重、重冠石、一格基台四层塔、偏心配重、六层多接口悬挑。质量、接触瓶颈、上层载荷与质心设计不同，不是旋转重计。

## 状态与提示
待放预览显示所有接口是否稳定，失败也允许真实尝试并可撤销。放置失稳、全部稳定但未达目标都有独立反馈。胜利只上报一次且锁定；暂停锁定；重开清空；撤销恢复之前一次放置。没有时间压力。

提示保留当前已放前缀，先按原创参考方案优先顺序搜索候选位置，每一候选都重新验证全部接口；最多 20,000 个状态。找到结果仅报下一块位置，超限不宣称无解，穷尽失败则明确当前前缀无法续搭。操作半格按钮、范围滑杆、数值框，键盘左右；过滤修改键及自动重复。
