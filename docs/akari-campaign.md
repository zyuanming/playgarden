# 灯照花园 · 36 关

第91款独立游戏：Akari / Light Up。不是旋镜光路或熄灯谜阵的变色版。玩家选择灯的位置，灯沿四方向照亮至墙；数字墙要求相邻灯数；任何灯不能照到另一盏灯。所有白格都亮且全部约束成立才赢。多条光线可以在无灯的白格交叉。

## 原创关卡

固定种子9102026，4章各9关，共36关，棋盘4×4、5×5、6×6、7×7。生成器从原创建墙开始，求合法布灯、导出数字，再逐个删数字而保持唯一解；旋转和镜像统一编码去重。每关保留墙形、编号和解法证书于 docs/akari/campaign.json。运行 python3 scripts/akari/generate.py --check 重现。唯一解不等于无需试探；这里没有声称全关都能仅用局部推理解决。未做任意图同构去重。

运行时题库不包含答案。提示用当前灯与×标记进行20000节点预算的约束搜索，只指向下一盏灯而不自动操作；无解会要求检查当前标记，预算耗尽不会误称无解。数字下始终显示已放/要求数量。撤销、暂停、重来、存档恢复与完成锁定通过外壳协议工作。
