# 天平等式

用整枚筹码和四个有符号整数表示 ax + b = cx + d。每张牌只可用一次，且同一运算作用在左右两边。游戏中的除法要求四组筹码分别均分，不能把整枚筹码变成分数。普通代数允许分数。达到 x = 常数即可通关，接受所有合法证明。

100 道原创题。第 1–12 关、存档和完成记录保持不变。新增五章：

- 13–30：整组先后，在三步内安排除法与加减。
- 31–48：有符号筹码，处理两边的负数项。
- 49–66：先扩再分，先乘再安排整组除法。
- 67–84：两次分组，考虑前一次除法对后续步骤的影响。
- 85–100：整组证明，在最多八张牌中挑出六步解法。

预览和提示不耗牌。撤销恢复筹码和步数；浏览器存档只回放合法牌号。提示从当前等式搜索余下步骤，不使用参考证明。第 100 关里，有一步虽然维持等式成立，却会让剩余步骤不够；四条可行路线都得到同一个解。
