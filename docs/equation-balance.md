# 天平等式

用整枚筹码和四个有符号整数表示 ax + b = cx + d。每张牌只可用一次，且同一运算作用在左右两边。除法须把四组筹码分别均分，不能让整枚筹码变成分数；这是游戏的表现限制，不是普通代数的限制。达到 x = 常数即可通关，接受所有可行证明，不限制某一条路线。

12 道原创题从一步消掉常数到五步筹划。第 12 关可用三条不同的五步路线得到相同的 x = 3，但先用 ×2 会在当前卡牌和步数下走入死路。预览和提示不消耗卡牌，撤销恢复筹码和步数，浏览器存档只回放合法牌号。提示在剩余操作和预算内搜索，从实际等式开始，不使用参考证明。
