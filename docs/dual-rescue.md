# 双伴救援

八张原创、手工构造的合作规划地图。两个角色绝非同质步行者：蓝伴能过水并操作 b/p，橙伴能过热地并操作 a/q。两者必须互相打开专属路线，且必须分别亲自到 X/Y 出口。与已有单角色迷宫、滑冰借位、火车时刻等规则独立。

## 机关
- b 只有蓝伴踩上才激活，永久打开 B/C；a 只有橙伴踩上激活，永久打开 A/D。
- 蓝伴站 p 暂时开 C，橙伴站 q 暂时开 D。闸门关闭后已经站在门格上的角色仍可走出，但不能再次走入。
- 角色不能同格，普通地面共同可走；出口不移除角色，允许让路。

前四课依次为隔岸互开、远端取钥折返、共享窄桥、分地形环绕；后四课加入蓝踏板护送、橙踏板回报、双向锁存接力、双谷回环综合。布局和依赖不同，不按旋转计数。

当前状态提示使用 20,000 状态上限 BFS，找到路线则只展示第一步，未找到明确说搜索上限内未找到，不宣称无解。撤销同步恢复位置和锁存，暂停禁用玩法，终局一次上报并锁定。键盘 1/2 切人、方向键或 WASD，过滤重复/修饰组合；移动端伙伴按钮和 44px 方向键。
