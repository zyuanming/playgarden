# 弹簧节拍

12 道原创振动谜题。选向左推、等一拍或向右推，先看下一拍的落点和速度，再确认。两种方向的推力分别计数。门区只在标注的拍检查落点，不是实体挡墙；推力不足或错过门区的动作不能确认，不推进、不耗推力。只有目标拍的位置和速度都相符才过关。提示不提交动作，撤销恢复上一拍的完整状态。

小车使用无摩擦理想弹簧模型。每拍走过四分之一周期，速度值按角频率归一化。出发状态为 (x, v)，施加速度增量 k 后，这一拍结束时为 (v + k, −x)。游戏只采样指定拍，但动画沿中间的连续轨迹。系统启用减少动态效果时立即显示下一拍，保留所有状态、门区和预览。键盘可按 Tab 到各按钮，再用空格或回车。大厅保留已完成记录，未完成局不跨刷新保存。

代码、关卡和 SVG 封面均为 GPL-3.0-only 原创，无第三方素材或新依赖。验收：`npm run test:e2e -- e2e/spring-beat.spec.ts`。
