## 集成边界

- 独立 iframe 防止全局 DOM 和按键污染主站；共享同源存储由严格 `playgarden.a-dark-room.v1.` 键空间隔离。
- 原 5 处字符串求值换成验证属性路径；拒绝原型键。导入仅接受有大小/深度/类型限制的原 v1.3 JSON 数据和 61×61 地图；无效内容不覆盖现有保存。Base64 使用浏览器原生 UTF-8 编解码。
- 保留原背包界面在根对象写入的已知物品数值镜像兼容性，原版真实导出仍能回读；它们不授予额外对象路径。原 jQuery 深拷贝会缩短可见性数组的末尾空洞；导入把缺失格还原为未探索，地图本体仍严格61×61，绝不扩大已探索区域。叙事改为滚动保留最近80条，避免旧渐变遮罩的裁剪算法误删可见消息。
- 全局计时和 Date 在 iframe 内统一暂停，冻结收入、冷却、战斗、jQuery 动画和飞行；恢复不追补暂停时长。退出保存并清理任务、观察器和宿主消息监听，销毁 iframe。
- 响应式村落/背包布局及可滚动完整地图；太空保留 700×700 逻辑坐标，只缩放显示。方向按钮支持点按、长按、滑出和取消清键。
- CSP 只准本地脚本，禁网络连接、内联脚本和动态求值。完整可编辑运行代码随站公开，完整许可证在 `public/adr-original/LICENSES.txt`。

## 验证范围

`scripts/adr/verify-sources.py` 只做源哈希、许可、结构和原数据核验，不执行游戏。`scripts/adr/prepare.mjs` 使用 TypeScript AST 做静态转换。

定向浏览器旅程 `e2e/a-dark-room.spec.ts` 覆盖真实首局生火和造陷阱，随后使用明确的中后期存档检查点检验岗位收入、补给、原地图探索、实际战斗与死亡返回、原预算升级、陨石坠毁和完整上升结局，再检查资源继承和其他游戏存档不受影响。测试以种子 1562020 与浏览器虚拟时钟加速等待，正式游戏随机性、计时参数、费用、胜负规则不变；这不表示从零手打完整长战役或穷举所有分支。仅在实际双端旅程和画面检查通过后发布。
