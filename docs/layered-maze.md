# 层梯迷宫

在同楼层上下左右行走，自动收集邮戳。踩到楼梯格后才能主动换层；楼梯首次通过后两端都关闭，但楼梯格仍可步行通过。没集齐邮戳时出口只是普通格。预览楼层不会推进游戏；撤销一步同时恢复位置、邮戳、楼梯。浏览器按关卡保存移动记录，可刷新后继续，也可以主动重来。

12 道原创谜题使用 2–3 层、最多 6 座楼梯和 3 枚邮戳。关卡 2 如果过早返回会无路可走，撤销该次换层即可恢复可解；关卡 12 按正式规则至少需要 24 步，假如楼梯可重复使用只需 14 步。提示从实际位置、已关闭楼梯、已收集邮戳做广度优先搜索，不改变局面；参考路线仅用于浏览器验收，不随关卡模块发给玩家。

场景、程序、关卡与 SVG 图形均为 GPL-3.0-only 原创，无新依赖。操作验收：`npm run test:e2e -- e2e/layered-maze.spec.ts`。
