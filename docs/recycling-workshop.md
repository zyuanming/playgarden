# 回收分拣

拆解台上每个物件是二叉结构：接头用卡扣或螺丝固定，最末端是纸、金属、玻璃或残余。只能拆最外层已露出的混合接头，每次消耗一个对应工具。露出的单一材料整件入箱，不必拆内部接头；残余不计数。只要三种材料都达到最低回收量，就可以留着其他物件不拆。

12 道原创题，包含自动入箱、先拆外层、为关键接头保留工具和多解。选接头只预览费用和新增材料；确认才用工具。提示按当前状态找合法路线，不更改工具或已拆接头。撤销恢复上一步的材料和工具，过关记录由大厅保存，未完成局不跨刷新保存。按钮均可触屏，或用 Tab 和空格／回车操作。

这是简化的游戏模型，并非实际分类指南。源代码、关卡和 SVG 封面均为 GPL-3.0-only 原创，无第三方素材或新依赖。验收：`npm run test:e2e -- e2e/recycling-workshop.spec.ts`。
