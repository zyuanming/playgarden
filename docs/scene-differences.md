# 找不同花园

Original GPL-3.0-only comparison game, eight authored scene descriptors and SVG objects. No external imagery, code, commercial assets or quoted text.

Compare nine paired numbered regions. Every round has five changed regions, each with one visible change: object kind, color, number of white dots, or flag direction. The actual descriptor differences determine validity, rather than a hard-coded completion button. Click either corresponding image region to mark a difference. Unchanged regions provide feedback without penalties. Repeated markings do nothing.

Each lesson introduces or mixes observation categories. Shapes, color, count and orientation all have explicit SVG render effects; the two pictures use matching region coordinates. There is no timer. Current-state hints highlight one remaining region without marking it, undo removes the last found region, reset clears the round, and pause/win lock all inputs. Native buttons allow touch or Tab/Enter/Space.

A single final targeted E2E invocation covers genuine first/final completion, independently comparing DOM-exposed rendered descriptors, an unchanged-region mistake, pause, undo, reset, hints, mobile taps, keyboard, screenshots and overflow. No unit or exhaustive campaign suite is requested.
