# 弹珠花台

原创 GPL-3.0-only 固定挡板弹珠游戏。八个花鼓布置、物理代码、中文说明和 SVG 球台为本项目原创。无第三方素材和新增依赖。

规则：重力使球下落。圆花鼓碰撞反射并轻微加速，实际碰撞点亮该花鼓；固定在下方的左右线段挡板抬起时，真实接住下落球会给球向上冲量并计回击。不能自由搬动挡板追球，不是打砖块的自由横移球拍。

课程分别为中央花鼓入门、左右双鼓、三色高台、侧轨转向、左右各回击、三角花阵、阶梯花台、综合奏鸣。每关都要求点亮全部花鼓和规定次数的回击，部分关要求左右各至少一次。不会因按钮点击次数、时间或发球次数直接胜利。

明确的简化：使用固定重力、圆形碰撞体和线段碰撞体；抬起挡板接球采用固定向上和向内冲量，不声称是刚体角动量模拟。三个可选发球口提供不同入口。练习不限球数，落袋后本轮花鼓与回击累计保留，重来全部清空。

输入：球台获得焦点后 A/D 或左右方向键控制，空格发球；触屏轻点左右挡板激活 320 毫秒，按住持续抬起。实时无撤销。暂停、失焦和卸载清空输入；暂停/卸载取消 RAF，恢复不追赶暂停时间。胜利后模拟和全部内部按钮锁定。

提示读取球当前坐标、速度、未亮花鼓和回击目标，提供局部建议，不写入比分或代发球。E2E 仅观察实际渲染状态，普通键盘/.tap 发球与抬板，完成首末关，并验证暂停、重来、终局锁定与截图。贡献阶段未运行 E2E 或任何测试套件。
