# 胞子争园：30 个原创战术练习与完整对局

第95款候选独立玩法。只有对应提交完成 CI、独立复核、部署和公网验收后才算已上线。

30关分为五章，每章6关：
1. 第一颗孢子：复制、跳跃、跨越石头、斜角转化和确认预览。
2. 落点涟漪：选择能够转化目标数量紫子的落点。
3. 看过回击：在对方最不利的一手回击后，达到绿子数量目标。直接获胜也通过；终局输棋或和局不通过。
4. 两手合围：保证在最多两次绿方行动内获胜；独立检查排除了立即获胜。
5. 三手终章：保证在最多三次绿方行动内获胜；独立检查排除了两次行动内强制获胜。

每关都允许所有合法且达到目标的答案，不强迫玩家照抄预定路线。复制的不同相邻源棋子可能产生同一后继局面，只算同一种策略选择。不同章节的目标明确展示。最后两章是真实交替下棋，电脑尝试破坏目标。自由对弈是完整7×7局，不额外算有限关卡。

首批只计30关，不宣称100关。教程6关为手工布局，其他24关由固定种子951008构造、按目标和反例筛选；没有采用上游关卡、镜像或旋转模板膨胀数量。`docs/ataxx/campaign.json`保存作者的证书与解法，运行时`ataxxLevels.ts`只包含题面和公开目标。

规则改编来源与许可见[来源说明](ataxx-provenance.md)。独立审查使用另写的Python位棋盘规则与极小极大求解，不调用作者求解器。30题全部有必达策略、D4互不重复，16题有多个规范化正确首着，每题都有至少一个错误合法选择。浏览器桌面/触屏尺寸模拟不等于真实手机硬件或完整无障碍认证。

提示分析当前棋局，不自动代下。自由对弈提示明确为有限深度策略建议，不保证必胜。电脑和提示使用可取消Worker、节点和时间双预算；没有Worker时使用有界本地备用分析。暂停、离开页面、撤销、换关、重来和模式切换都会废弃旧任务。
