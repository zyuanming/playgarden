# Parity / 步步同数 (MIT)

Original work: Abe Fehr, Parity.

Fixed source: https://github.com/abejfehr/parity/tree/730ecbd24d4cd821bd236f2a441f4e5e2b22654f

The native adaptation ports the original continuous-cursor 3×3 arrival-cell +1/-1 rules and equality condition, with all 100 original levels (50 ordinary and 50 black/white) retained. The exact first-party editable sources and full story data are preserved in vendor/parity-original/upstream. No old jQuery/TouchSwipe/RequireJS runtime, generated mixed bundle, binary artwork, Facebook, Google Analytics, or Google Fonts is deployed. The original source snapshot remains unchanged, including historical references; it is not executed.

The typed gameplay core and original level data retain MIT attribution. Playgarden Chinese interface, native input/lifecycle integration, persistence, undo, teaching hints, responsive CSS and new SVG artwork are GPL-3.0-only. These modifications do not change the original puzzle data or core win rule. The two modes count as one game.
