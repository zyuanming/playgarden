# 踏格方阵 / Hexahedral

完整适配 Matthew Miner 的 Hexahedral，固定 a2641001e13afe15ca8488be7d739203471fee77，MIT，Copyright (c) 2018 Matthew Miner。来源为用户指定的 bobeff/open-source-games 所列 leereilly/games 中的 Hexahedral 链接。

保留原30关（初阶、进阶、高阶各10）：每格布局、起点、缺口、移动预算逐项一致。走入目标格时翻转，不能跳跃/斜走/走进缺口；起点不自动翻转。个别原关卡从缺口出发，允许离开但不能再进入。先检查全压下，再检查步数耗尽，末步达成算赢。

替换原全局 Redux/virtual-dom/FastClick 界面，使用本站现有 React，不安装老构建链。新俯视方块由CSS绘制，SVG卡图原创，系统字体，无第三方图形/音效/网络请求。原README所列 Game Burp/RCP Tones音效权利未逐项确认，因此音频资源不使用、不再分发；音频并非解谜规则。原35份第一方文本源码和完整MIT保留，仅供审计，不作为旧构建运行入口。

本站明确点击下一关和重新尝试，替代原胜负后的延时自动切换。没有后台计时器或全局输入监听。只在棋盘聚焦时接收方向键，触屏点格/方向键均可。暂停锁定操作，退出不保留监听；命名空间按游戏/原关卡保存合法移动历史，读取时按原规则重放验证，无eval。

生产构建、桌面/手机实测和截图尚未完成，不计上线。预备旅程为首关真实失误/重试及恰好3步胜利、15关12步、30关23步胜利，刷新保存、暂停、退出、320px画面。只为三个代表关卡规划E2E路径，没有运行全关卡证明或单元测试。
