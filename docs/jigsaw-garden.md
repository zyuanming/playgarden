# 花园拼图

原创 GPL-3.0-only 图片拼图。八幅程序化 SVG 原创场景是风车花田、荷塘月色、灯塔海岸、热气球节、森林小屋、星夜营地、果园小径、四季温室。它们有独立构图、物件、色彩、跨片线索，不是同图旋转或换色。没有外部图片、新依赖或改编游戏源码。

原图切成 6、9 或 12 块互补凹凸拼片。共享边界使用同一条曲线、相反朝向，因此相邻拼片真实互补；图像在各拼片上连续。不是空白滑块游戏，也不是几何库存马赛克。允许在整张桌面任意位置拖放、点击放置、键盘移动，以及按 90° 旋转。正向、离目标中心不超过 14 个画布单位时吸附并固定。所有拼片归位才胜利，不根据点击次数推断。

完整图参考可以展开或收起。提示只选出当前未归位的一片，标记正确轮廓并说明剩余旋转次数，不修改拼片状态。

控制：轻点拼片后轻点画框位置，或直接拖动；R/旋转按钮顺时针旋转。Tab/Enter 选择拼片，方向键每次移动 5 单位，Shift+方向键移动 20 单位；触屏亦有四个挪动按钮。一次拖动记一个撤销步骤，旋转或按键移动各记一步。暂停中断拖动并回到该次拖动之前；暂停和胜利锁住编辑，成功不允许撤销。组件不运行定时器。

最终 E2E 使用真实键盘移动/旋转和移动端 .tap 选片/放置完成首末图；包括首图与末图开始、完成截图，提示不修改棋盘，撤销、暂停、重来、终局锁定和溢出检查。贡献阶段只运行 TypeScript 检查，未运行 E2E、浏览器或单测。
