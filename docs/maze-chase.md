# 星豆迷宫

原创 GPL-3.0-only 回合制采集追逐游戏。代码、八张不同拓扑地图、中文说明及 SVG 图画均为本项目原创，无外部素材或新依赖。

每次有效移动或等待后，所有守卫沿可查看的固定路线前进一步。不是实时追踪 AI。墙不消耗回合；玩家与守卫同格或迎面交换位置都会失败。必须收齐本图所有星豆并抵达出口。守卫当前位置和下一步位置始终可见。八图依次练习外圈绕行、长廊、回字路线、双巡逻、口袋支路、双桥、不同周期错峰和综合回环，不是地图旋转。

提示对当前玩家位置、已采集集合及巡逻周期进行最多 70,000 个节点的广度优先搜索。完整安全路径存在时只指下一步；达到上限时明确降级为“一步安全、不保证通关”。提示不改变状态。暂停、成功和失败锁定方向操作。成功后不可撤销；未结束时撤销恢复一个完整回合。失败需重来。无计时器和后台动画。

输入：棋盘方向键 / 空格，或触屏方向和等待按钮。路线详情为行列坐标。

验证：提供 e2e/maze-chase.spec.ts 的单次最终桌面与触屏流程，使用可见提示及普通按键/轻点完成首关与末关；覆盖暂停、重来、撤销、终局锁定和截图。贡献阶段没有运行单测、关卡证明扫描或浏览器测试；由集成方执行最终定向 E2E。
