# 递归树园

100 道原创谜题。一张规则只作用于这一回合开始时所有同类型的芽；产生的新芽不会在同一回合继续长。A/B 是可以生长的芽，X/Y 是不变的叶；括号中的第一项是左枝，第二项是右枝。只要在步数和末端数量上限内长成指定的有序树，任何合法操作顺序都允许。

前几关依次引入生长、左右方向和多芽同步；后续关卡组合互相依赖的规则，并引入更大的目标树。追加关卡由左右枝序推进到同时改造多芽、分配后续生长顺序，以及在七步和十四末端上限内生长成深树。保留原 12 关编号及已完成记录。提示从当前树和剩余步数搜索，已有分枝和成熟叶不可改变，最多检查 6,000 个状态。撤销恢复整次同步生长。只保存关卡完成记录，不保存半局。

界面、规则实现、图形、关卡均为 GPL-3.0-only 的原创内容，不使用新增依赖或外链。每关示例解可在 `src/games/recursiveOrchardLogic.ts` 中找到；实际获胜不检查操作历史。定向验收入口：`npm run test:e2e -- e2e/recursive-orchard.spec.ts`。
