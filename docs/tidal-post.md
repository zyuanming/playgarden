# 潮汐邮路

原创回合制路线谜题。100 道固定关卡，从单潮门、停靠台等拍到 A → B 邮戳和双等待路线。无计时、第三方素材或网络服务；卡片为项目原创 SVG。

每次合法走动或在停靠台等待，潮位按 0 → 1 → 2 → 0 推进。潮门检查到达时的潮位；撞礁、走错门、未取 A 就尝试进 B 都不消耗回合。未取齐邮戳可以经过邮站，但不算送达。撤销原子恢复位置、潮位、邮戳；提示对当前完整状态做有界广度搜索，只给下一步，不改棋盘。局间保存已通关编号，不保存未送达的中途盘面。

`src/games/tidalPostLogic.ts` 留有每关合法解法证书；不是限定解。桌面键盘和手机触屏通过 `npm run test:e2e -- e2e/tidal-post.spec.ts` 验收。


前 12 关、通关编号、动作和提示规则均不变。新增五章：辨认潮门（13–28）、停靠等潮（29–44）、双戳邮路（45–62）、带戳换潮（63–80）、夜潮终程（81–100）。52 个新关必须至少等待一次；末章的最短路线为 27–33 步。第 29 关有停靠台上的连续两次等待，第 100 关可用撤销从提前抵达邮站的死路恢复。只运行本游戏验收，包含 88 道新增路线的真实键盘/触控、旧第 12 关完成后进入第 13 关，以及刷新后保留通关记录。
