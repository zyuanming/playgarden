# 潮汐邮路

原创回合制路线谜题。12 道固定关卡，从单潮门、停靠台等拍到 A → B 邮戳和双等待路线。无计时、第三方素材或网络服务；卡片为项目原创 SVG。

每次合法走动或在停靠台等待，潮位按 0 → 1 → 2 → 0 推进。潮门检查到达时的潮位；撞礁、走错门、未取 A 就尝试进 B 都不消耗回合。未取齐邮戳可以经过邮站，但不算送达。撤销原子恢复位置、潮位、邮戳；提示对当前完整状态做有界广度搜索，只给下一步，不改棋盘。局间保存已通关编号，不保存未送达的中途盘面。

`src/games/tidalPostLogic.ts` 留有每关合法解法证书；不是限定解。桌面键盘和手机触屏通过 `npm run test:e2e -- e2e/tidal-post.spec.ts` 验收。
