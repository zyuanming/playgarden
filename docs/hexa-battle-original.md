# 六角远征 / Hexa Battle

完整规则改编自 Giacomo Tagliabue 的 Hexa Battle，固定 `fe97718def25736a4000e93efca6894530ba0c86`，MIT。来源链为 bobeff/open-source-games → leereilly/games → itajaja/hb。70份第一方源文件的 Git blob 与完整许可证保存在 vendor/hexa-battle-original。

原作是持续深入的回合制地牢，没有有限关卡集。保留八类可招募人类、八类怪物、十三类具体技能、飞行与四种状态、六角路径、原AI评分与行动策略、随机地图/敌群预算、金币奖励和生还者继承。初始一弓手三战士、零金币；战胜后只带生还者继续并恢复到各自初始属性，失败返回出发队伍。

原技能包括近战、远射、横扫、投石、滚石、龙息、火球、治疗、催眠、蛛网、防御、跳跃和传送。范围技能可伤及己方，耗魔、距离、状态时限均保留。护甲抵扣正伤害的原下溢错误修正为最低0，避免攻击反而加血。原AI结束战斗的内部信号由控制层正常收束，不作为页面错误。

不安装原旧版React/Aphrodite/animejs/color/store/lodash工具链。本站直接适配无依赖的原TypeScript规则，用现有React提供中文界面、键盘和触屏、可滚动战场、完整单位与技能选择、招募、撤回、存档导入导出。原game-icons.net素材没有足够逐文件权利记录，因此不复制，使用本站自绘汉字棋子和SVG卡片。没有外部字体、图片、音频或联网请求。

存档仅写 playgarden.hexa-battle.v1，验证白名单兵种、坐标、数值和状态。只在完整玩家行动或完整敌方回合结束后保存；若中途退出，恢复最近稳定行动。暂停阻止后续AI/动画任务推进，退出取消待执行任务与观察入口。重置只影响本游戏。

浏览器验收仍待完成，不在通过前宣称上线。计划以固定种子的真实首战，及明确的后期存档检查点，检验胜负、原预算招募、技能/状态、暂停/退出、恢复与实际手机显示；不冒称穷举无限深度。

实玩修复：原挖坑生成器在当前坑四周已无地面时仍反复抽取邻格，导致随机地图无法完成。适配仅在无可用邻格时改从其它地面继续，保留原坑数、地图半径、敌军预算和随机难度；使用同一测试种子复验第6层18个坑及原60点敌军预算。
