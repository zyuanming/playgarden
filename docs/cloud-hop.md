# 云朵弹跳

原创 GPL-3.0-only 竖向重力平台跳跃。代码、八个手工编排课程、矢量小鸟和云景均为原创，无外部图像或新增依赖。

小鸟受固定重力影响，水平输入有惯性。只有下降时足部真实穿过平台上表面且水平重叠，才会弹起。最高旗帜平台上发生实际着陆才胜利；没有按时间、镜头高度、按钮次数或预制路线触发的隐藏胜利。最高点推动相机向上，掉出下方可见范围后失败，需重来。

八关依次是宽云入门、交错云梯、不同高度间距、窄台制动、单侧攀升折返、高窄与低宽交替、双向穿梭、十级综合课程。平台均可由最大跳高约 121 单位、每秒最多 185 单位横移的运动能力逐级到达；这属于建设性设计说明，未进行逐关自动证明。

输入：键盘聚焦画面后方向键，空格开始或清空横移；触屏轻点左右为 220ms 短脉冲，按住可持续移动，停止按钮清空方向并自然减速。暂停、失焦、卸载清除输入；暂停和卸载取消 RAF，恢复时不补算暂停时间。实时游戏不提供撤销。暂停、失败和胜利均锁住控制。

提示只读取当前位置和上次落台，给出下一平台中心与当前方向建议，不执行动作或承诺完整路线。

最终 E2E 文件通过观察渲染状态和正常键盘 / .tap 控制完成首关、末关，包含暂停冻结、重来、提示无状态变更、终局锁定和起终截图。贡献阶段未运行浏览器、E2E 或单测。
