# 箭羽争地

原创 5×5、每方一子的 Amazons 风格教学变体，共八个非旋转的手工战术布局，使用岩石限定小花园。与 Ataxx 的复制染色、围棋提子、围栏竞走的格边筑墙有独立的动作与终局。

先像皇后移动，再从落点向八方向射箭；两者不能穿过棋子、岩石或箭。箭永久占据一个空格，可射回本次起点。对方轮到时没有合法移动即失败。

电脑作有限的当前可达空间与移动度评价，不是穷尽搜索。提示对当前状态或已选落点重新计算，清楚披露局部局限。半步取消不消耗回合，暂停保留半步；撤销先取消半步，完整回合撤销同时恢复玩家及电脑的移动和箭。同步状态引用防止连续事件越过阶段；终局禁用所有玩法控件、只上报一次。

八课包含地域计数、长射程、射回起点、连接点封锁、曲折狭口、岔路剪除、回转空间与综合分园，不是棋盘旋转或皮肤扩充。
