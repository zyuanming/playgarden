# CARD Q source notice

CARD Q (纸牌争先) is by ABA Games, copyright 2021, MIT licensed. The complete game source is preserved byte for byte from `abagames/crisp-game-lib-games` commit `cfb39d2f988feb5918eb83697145b5a35adabf58`, path `docs/cardq/main.js`, Git blob `4fc0a9d5ff569e572c3856b25e476f8a5924337c`.

The new game uses the existing local crisp-game-lib 1.0.2 renderer/input/replay implementation, sounds-some-sounds generated music and effects, jsfx and mml-iterator. Keep the existing full notices at `public/crisp-original/LICENSES.txt`, their full source archives and licensing evidence under `vendor/crisp-original`, and the shared lifecycle correspondence files. The new source map at `docs/cardq-source-map.json` identifies each component, commit and license path.

New Playgarden work consists of Chinese instructions, the thin React host selection, a read-only observer, the iframe document, original catalog SVG and targeted browser journey. These additions use GPL-3.0-only. Original card graphics and rank-10 sprite remain generated by the upstream source, and original generated BGM/SFX remain active through the existing audio lifecycle adapter.

No original gameplay or level has been shortened. This is an endless game, so its finite level count is 0. There is no finite campaign or final victory. The upstream duplicated `isPlacable` assignment in the idle check is deliberately preserved, including its AI scheduling effect. Existing Golf Cards differs substantially: it is a turn-based finite one-pile clearing exercise without rank wrapping, AI pressure, two-pile contention, moving boundary, replenishing queues or score multipliers.
