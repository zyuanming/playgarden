# 配方比例

游戏中的数量以格计。给一把标准勺分配固定格数，所有订单共用这把勺的配方，再分别选一到四勺。每杯成品必须同时满足目标比例和允许容量。杯里预装的材料不扣库存，最后合计所有新加入的原料。

- 1–3：固定勺容量、等比放大和预装量。
- 4–6：找同一配方在不同杯子中的可行勺数。
- 7–10：区分单杯达标和共享库存达标。
- 11–12：三杯同时计算；不能只检查其中两杯。

用 Tab 和 Enter 操作，也可直接触碰。试算不计通关，需要按交付；可以撤销上一次调整。完成记录留在浏览器，未交付的试算不保留。

比例用整数交叉相乘比较。成品向量各项除以最大公约数，显示为最简比；绝对容量独立校验。一勺 3:1 与两勺 6:2 化简相同，但总量分别是 4 和 8。

本作代码、12 道关卡和矢量封面均为 Playgarden 原创。不调用第三方游戏或资源。
