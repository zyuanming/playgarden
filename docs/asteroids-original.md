# 小行星航场 / HTML5-Asteroids

完整适配 Doug McInnes 的 HTML5-Asteroids，固定2016-01-13提交930301cbda83ed3b120f64b801d937d077ee2da0。原始第一方规则及几何为MIT，Copyright(c)2010 Doug McInnes；新中文界面、控制、生命周期、存储与卡片为GPL-3.0-only。来源链：bobeff/open-source-games所列leereilly/games中的HTML5-Asteroids。

## 完整机制

保持原桌面780×540逻辑场地，所有设备使用同一尺度。全方向旋转、惯性推进、子弹继承船速、环绕空间、三级陨石、分裂、飞碟随机射击、完整三艘飞船/安全重生/死亡/结束/重开循环和无限递增波次。原作没有刹车、超空间、小飞碟、奖励生命或有限终点，本适配也不添加这些规则。有限关卡数为0。

起始两颗大陨石，每波加一，最多十二颗；尺度6→2→2/3，每次三分裂。玩家击中大/中/小陨石分别20/60/180分，飞碟200分。玩家十发弹池，300ms间隔；飞碟三发弹池，660ms间隔。双方子弹存活超过1500ms才消失。首次飞碟30至60秒，后续原0至30秒计时从出场激活时开始。飞碟与陨石、敌弹与陨石也相撞，只有玩家命中计分。

## 明确的适配与修正

用完整纯TypeScript引擎替代旧全局对象与jQuery，但保留源中运动常数、平面坐标逆序、飞碟邻格避让及原阶段时序。重算当前碰撞几何与邻格占用，销毁立即生效，避免旧链表/重复碰撞/陈旧变换；重开清空所有弹池和阶段时钟。暂停使用停止的模拟时钟，退出取消RAF与输入监听。大帧延迟有界分步，随机安全生成有界兜底。具体保真与修正边界见源代码和mechanics-inventory.json。

触屏四按钮允许多指同时操作；键盘仅在本游戏聚焦时使用方向键/空格。暂停、窗口失焦与页面隐藏会清掉按住状态，恢复需明确继续。最高分使用本游戏专有键，不清其他存储；重进为新局。逻辑分辨率固定，画面响应式缩放。背景星点、HUD、系统字体、飞船定位圈及卡片由本站绘制；没有原音效，明确为静音呈现。
