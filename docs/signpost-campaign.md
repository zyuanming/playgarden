# 箭头路标：30 个原创有限关卡

第94款候选玩法，发布状态以确切提交的 CI、独立审查和部署验收为准。

- 5章各6关：3×3、4×3、4×4、5×4、5×5。
- 所有格子组成1到格数的一条有向链；箭头为八方向射线，允许跨越任意距离，跨过的格子不会被占用。
- 数字锚点必须处于正确位置，每格至多一个前驱和一个后继，不允许循环。可以从任意位置拼接，包括尚未锚定的中段；A1、A2等相对标签会随拼接重新编号。
- 和骑士周游的固定L步、一路向前操作不同，本作推理对象是不同方向/距离的后继、数字锚点间隔与多个分段之间的拼接。也不是一笔画的无向边覆盖。
- 原创确定性生成器 `scripts/signpost/generate.py` 使用种子940810。每题作者求解器计数到第2解，要求唯一解；排除旋转和镜像重复，并保留至少2处局部岔路、2次跨格和2次斜向移动。
- `docs/signpost/campaign.json` 保存解法和生成度量；运行时只包含箭头、锚点和元数据，不导入解法证书。
- 提示从当前实际连线做有界完整路线搜索。搜索建议如实标明，不自动代填；不把预算耗尽称为无解。
- 存档限定500步合法历史；暂停/终局禁用编辑，重复事件标记不会重放。键盘/鼠标/触屏均经真实控件操作。

[独立规则/唯一性审核](signpost/independent-review.md)已验证30题唯一、无旋转镜像重复，并以独立CSP和方程oracle差分核对运行时。作者生成和回放不替代独立证明。浏览器尺寸模拟不是移动真机或完整无障碍认证。
