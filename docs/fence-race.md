# 围栏竞走

原创 5×5 Quoridor 风格教学变体，八个手工设定的起点、库存与围栏残局。不是标准 9×9 完整比赛，不使用第三方源码或关卡。

## 规则和独立性
你向顶边，电脑向底边，谁先到岸谁赢。每回合移动或放置一面恰好遮挡两条格边的围栏。禁止墙重叠、中点交叉，BFS 检查双方仍有到达目标行的路径（该检查不把棋子当墙）。对手相邻时优先直跳；直跳被墙或边界挡住才可侧步。与迷宫寻路、Ataxx、围棋和已有双符平衡均有不同动作、状态和获胜规则。

八课依次涵盖距离、直跳、受阻侧步、留路、行动机会成本、长围栏、交错路线和综合残局；不是棋盘旋转扩充。

电脑评价下一手双方最短路差，平分优先走路。提示只比较玩家一步和电脑一次确定回应；不宣称全局必胜。全回合原子更新、暂停禁用、撤销双方一轮；失败可撤销，胜利锁定且只上报一次。键盘使用原生 Tab、Enter、空格，修饰键和重复激活被拒绝。

## 验证状态
包含唯一目标 E2E `e2e/fence-race.spec.ts`：首末关实际到岸、横墙放置与撤销、暂停、重开、当前提示、键盘/触屏、终局锁、控制台与水平溢出检查，以及首末初态截图。未运行 E2E、浏览器、单元测试或全关证明；由集成方执行最终目标 E2E。
