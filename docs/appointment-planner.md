# 活动日程

一人从礼堂 09:00 出发。点击活动可预览从当前位置出发的步行、等待和活动时间，再确定加入顺序。到早自动等开门，结束不得晚于该活动关门和全局截止。按最早可用时刻开始不会让固定顺序更难。部分关卡还要在截止前确认走回礼堂；最后一项合法也可能导致返程太晚。

100 道原创题。第 1–12 关及其存档不变。新关卡按五章递进：

- 13–24：开门与关门。在同一地点安排服务窗口。
- 25–40：步行与等待。把步行和提前到达的等待都算进去。
- 41–58：排除错序。考虑一个选择会不会堵住后面的活动；第 58 关有两种合法安排。
- 59–78：留足返程。完成活动后需要确认走回礼堂。
- 79–100：准点回礼堂。最多六项活动；第 100 关两种相近的安排分别在 12:25 和 12:20 回到礼堂，只有后者准时。

提示按现有顺序搜索并预览可行的下一项，不作提交；撤销恢复地点和时刻。浏览器本机存档按关卡回放合法活动，并单独校验返程完成状态。
