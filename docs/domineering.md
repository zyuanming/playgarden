# 横竖争地 · Domineering

经典方向对弈规则，全部代码、100 个固定关卡、SVG 插图均为原创 GPL-3.0-only；没有第三方代码、字体、图片或音频。不是骨牌接龙、拼图或围地换皮：双方使用不同方向的 1×2 骨牌，交替占空格，无合法落子的一方输。

## 关卡

`scripts/domineering/generate.mjs` 使用固定种子 20261020 构造 4×4 内的连通空地。每个开局至少两种横向和竖向落法，先手存在制胜路线；八种旋转/反射规范化后无重复。100 个稳定 ID 及双方交替合法证书固定在 `domineeringLevels.json`。空格数递增仅为入门顺序，不宣称严格难度递增或唯一解。生成器是题库制作工具，不进入运行时。允许多种合法赢法。

## 对弈与提示

所有落子只能消耗两格，因此最大深度为 8，精确搜索缓存上界为 2×65536 个状态，不使用无界搜索、后台计时或网络。电脑优先选择制胜步；没有制胜步时选择稳定的第一合法步。提示分析当前局面，说明是否存在对完美对手的必胜路线，不自动落子或假装人工逻辑。撤销回退玩家和电脑的一整轮。输局允许撤销；赢局锁定。确认按钮防误触，预览不改变局面。

## 验收边界

按仓库 AGENTS.md 只运行生产 build 和本游戏一轮 desktop/mobile 专项 E2E，不运行单元测试和全关卡扫描。首、中、末关真实输入，非法位置、提示、暂停/恢复、整轮撤销、重来、胜利锁定和移动宽度均需覆盖。移动尺寸 Chromium 不等于真机认证。线上必须等 CI 与发布提交一致后再计入已上线数量。
