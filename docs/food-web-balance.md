# 食物网平衡

每季先将当季的叶片、种子补给计入开场库存。昆虫、小鼠、猫头鹰各选一张牌。三张牌的成本必须合起来从开场库存扣除；本季产出结算后存下，只能从下一季起使用。所选牌、开场库存、合计扣除、结算后库存和末季目标都可见。结算缺货时保持库存和季数不变。完成全部季节并满足所有目标范围才过关。

12 道原创谜题。第 2 关演示合计超额，第 3 关演示不能预支，第 9 关两种解法都接受。第 12 关要区分本季缺货与虽然合法但再无通路的结算。提示不改库存或选项；撤销上一季结算会重开该季。草稿和进行中的季节不跨刷新保存，过关记录由大厅保存。每组选项可触屏点选，也可聚焦操作区再用 1 / 2 / 3 轮选、A 结算。

这是对食物网资源与时序的简化策略模型，筹码和数字不代表实际种群。实现、关卡与 SVG 插画均为 GPL-3.0-only 原创，无第三方素材或新依赖。验收命令：`npm run test:e2e -- e2e/food-web-balance.spec.ts`。
