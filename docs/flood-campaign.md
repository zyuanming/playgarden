# 染色花园 · 100 个原创关卡

## 独立规则

从左上角起点开始，对整片上下左右相连的同色区域换色；新的相邻同色区域并入下一回合。目标是在步数内让全盘同色。对角不连通，格子不删除、不下落、不换位，因此与花簇消除、熄灯谜阵、地图着色等已注册玩法不同。

选择颜色只预览，再确认才执行；不接壤的颜色也耗一步，当前颜色不可选。前两章在精确最短路之外多给一步，后三章需要最短解。用完步数可撤销或重来；通关锁定编辑和撤销。没有时限。

## 关卡、信息差与梯度

五章各 20 关；稳定 ID `flood-001` 至 `flood-100`。4×4 / 3 色 / 3–4 步，5×5 / 3 色 / 4–5 步，6×6 / 4 色 / 5–6 步，7×7 / 4 色 / 6–7 步，8×8 / 5 色 / 7–9 步。地图是原创固定随机种子生成后经过过滤的具体棋盘，章节内部先按精确最短步数、再按搜索状态数递增。

全部排除 D4 旋转、镜像及颜色置换等价地图。这里只宣称空间与换色去重，不宣称所有抽象区域图在任意图同构下都不同。第二章起每关至少有一个非最优开局；这由各开局的独立最短距离记录证明，玩家必须比较选择而非执行唯一按钮。地图无隐藏答案或即时正确性标记，提示不会自动执行。

`python3 scripts/flood/generate.py --check` 可复现地图与证书。生成器把原始色块缩成区域邻接图，用整型位掩码 BFS 求精确最短路径；运行时则对实际格子队列填色，用已连接格集合做 BFS 去重。两条实现路线分别提供证书与运行时搜索交叉校验。`docs/flood/campaign.json` 保留合法解法、开局距离、区域数、搜索状态数和规范化去重键；不会导入玩家模块。

## 提示和续玩

提示依据当前盘面搜索，并用剩余步数判断建议。如果最短路线已超预算，会建议撤销。搜索上限 12,000 个不同连通区，达到上限明确说明“暂时没有可靠建议”，不报告无解。题库生成上限 6,000，当前已选题目的最大生成搜索状态数为 4,899。

本地只保存版本、关卡 ID 和实际换色动作序列。载入时从初始盘面逐步重放检查；不能直接写入一张完成棋盘伪造结果。存储不可用仍能玩，但不能跨刷新保留。完成成绩沿用大厅现有机制。

浏览器旅程通过可见选色/确认按钮游玩，不注入组件状态或存档伪造通关。含首/中/末关实际PNG、预览与终局、键盘、触控模拟、暂停/继续、撤销、重来、当前局面提示、高索引刷新续玩和320px横向溢出检查。实际通过范围以对应提交CI和像素复核结果为准。手机尺寸Chromium不等于真实iOS/Android或全面无障碍认证。
