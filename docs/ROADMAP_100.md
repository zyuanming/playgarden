# 至少 1000 款优秀游戏的长期路线图

长期愿景是至少 1000 款优秀游戏，以下是已实现项目与早期候选，不代表完成目标。当前包含 90 款，共 2171 个有限关卡及无尽模式；其余是候选。每次完善一种独立规则，先验证关卡深度、交互与来源，再接入大厅。经典规则采用原创代码、原创关卡和原创图形；Slant 已实际移植上游 MIT 生成源码，具体提交、完整许可证和改动见 slant-migration.md。

## 什么才计为一款游戏

- 有独立规则、玩家决策和获胜条件，不能只换图片、颜色、数字大小或难度。
- 能从进入、学习、操作、失败/纠错到通关完整走通。
- 有触屏与键盘路径、暂停/重来/提示/撤销的适用实现；特殊机制需在模块中说明。
- 关卡可解，教学提示解释因果；随机生成要有验证或拒绝不可解盘面。
- 代码、关卡、图像、音效、字体和商标来源清楚，不从搜索结果直接复制资源。
- 无广告、追踪、账号、聊天或儿童个人数据采集。
- 单元测试、状态回归、桌面与移动尺寸浏览器验收通过，保持主分支可用。

## 迁移与许可门槛

外部开源项目只是候选，不会因为进入本文件就直接复制到主程序。允许宽松许可的代码也必须检查附带素材、第三方商标、在线请求及依赖。外部 copyleft 项目仍须逐项评估与 GPL-3.0-only 主程序的兼容性及分发义务；目录或 iframe 隔离不会自动消除义务。每个实际引入的外部模块会保留完整上游声明与固定版本记录。

## 发布节奏

1. 按维护者当前授权的 main 开发流程实现一款真实模块与关卡。
2. 自动验证所有关卡，完成桌面/移动尺寸浏览器流程，独立复核截图。
3. 修复状态中断、换关、撤销、计时器与加载失败。
4. 主分支只接收通过检查的批次，更新真实数量与来源。
5. 根据试玩反馈调整优先级；质量门槛高于数字。
