# 理想滤光与谐波工作室

这两个原创 MIT 模块各有 12 个手工编写的关卡。目标数据与用于回放的示例解法分别存放；游戏判定和提示搜索不读取示例解法。它们不使用新增依赖、网络、音频、计时压力或外部素材。

## 理想滤光 Spectral Filters

### 模型和规则

- 1–2 束公开的 RGB 入射光，每束有 1–2 个滤片槽。
- 库存为 1–6 片具有独立身份的滤片。相同规格的两片也各自占用库存；同一片不能出现在两个槽中。
- 每片给出 R/G/B 三个有理数透射率与整数成本。每个通道分别乘上所有叠片透射率；不同光束的对应通道相加。
- 空槽不改变光，也不消耗成本。玩家可以替换、取回滤片；布局总成本不得超过公开预算。
- RGB 数值不会截断到 1。色块为了屏幕显示会截断，但数字不会；匹配三个精确分数并符合库存与预算才通关。
- 这是理想三通道光强教学模型，不是颜料混色或真实光谱模拟，也不提供设备或健康建议。

公开数据验证限制：光源每通道 0–3，目标每通道 0–6；分数分子 0–16、分母 1–16；透射率 0–1；滤片成本 1–6；预算 1–24。作者关卡使用更小的数值。乘加采用约分后的精确有理数，当前边界保持在安全整数范围内。

### 提示与接口

`searchSpectralFilters` 直接枚举当前题目的物理分配，最多 2,401 个完整候选；不重复使用滤片并剪去超预算分配。它寻找与当前局面接近的合法解，先取回不匹配的占用，再提供放片建议。小空间同步完成。结果区分 found、exhausted、budget、cancelled、invalid；预算耗尽不会被解释为无解。

- 默认组件：`src/games/SpectralFilters.tsx`
- 关卡：`spectralFiltersLevels`，稳定 ID `sf-01`–`sf-12`
- 证书：`getSpectralCertificate(levelIndex)` 返回新数组，顺序为光束 1 的所有槽，再光束 2 的所有槽；元素为库存索引，`-1` 为空槽。非法关卡索引返回 null。
- 规则入口：`createSpectralState`、`moveSpectralFilter`、`undoSpectralFilter`、`spectralWon`、`spectralOutput`
- 操作选择器：`[data-spectral-slot="0"]` 等原生 select；值为库存索引或 `-1`
- 观测选择器：`[data-spectral-game]`、`[data-spectral-board]`、`[data-spectral-output]`、`[data-spectral-won="true"]`
- 本地撤销：`[data-spectral-undo]`

## 谐波工作室 Wave Studio

### 模型和规则

每台振荡器产生 `a × cos(2πft + φ)`。关卡公开可选频率、振幅、相位、必须开启的台数、总振幅预算，以及 1–4 次谐波的四个余弦系数 C 与四个正弦系数 S。

- 1–3 台振荡器，频率是 1–4 的离散整数，振幅是 0–3 的离散整数。
- 相位只取 0°、90°、180°、270°。它们分别加入 +a 的 C、−a 的 S、−a 的 C、+a 的 S。
- 振幅 0 表示静默。频率与相位可以预设，开启台数只计算非零振幅。
- 同频率的系数相加。不同频率各自独立，既可以增强，也可以相消。
- 玩家可以暂时超过总振幅预算并继续调整或撤销；只有预算、必须开启台数和八个整数系数全部符合时才能通关。
- 目标与当前曲线使用同一纵轴范围。曲线是辅助采样视图，获胜条件不使用近似像素或采样误差。
- 这是有限谐波数学模型，不模拟真实声学设备；无音频或自动播放。

公开数据验证限制：目标系数为 −9–9 的整数，总振幅预算为 1–9；允许设置的笛卡尔积最多 `(4 × 4 × 4)^3 = 262,144`。

### 提示与接口

`createWaveSearch` 返回可取消、可分步的公开设置枚举器。每个 `step` 最多检查 256 个设置，总预算最多 262,144。组件通过可清理的定时器分批执行，允许搜索期间继续操作；任何新设置、撤销、取消、暂停、重置、换关或卸载都会取消旧搜索。提示每次只建议当前设置到一份合法解之间的一个字段修改。

- 默认组件：`src/games/WaveStudio.tsx`
- 关卡：`waveStudioLevels`，稳定 ID `ws-01`–`ws-12`
- 证书：`getWaveCertificate(levelIndex)` 返回对象深拷贝数组；每个对象为 `{ frequency, amplitude, phase }`。非法关卡索引返回 null。
- 规则入口：`createWaveState`、`moveWaveOscillator`、`undoWaveOscillator`、`waveCoefficients`、`waveWon`
- 操作选择器：原生 select `[data-wave-oscillator="0"][data-wave-field="frequency"]`；字段为 frequency、amplitude、phase
- 观测选择器：`[data-wave-game]`、`[data-wave-board]`、`[data-wave-searching]`、`[data-wave-coefficient="1"]`、`[data-wave-won="true"]`
- 操作按钮：`[data-wave-undo]`、`[data-wave-cancel]`

## 生命周期与无障碍设计

两个模块都实现 GameProps 的关卡、重置、暂停、提示、撤销和完成回调。获胜后编辑与本地/外部撤销都锁定，直到重置或换关；提示和撤销 token 在暂停或获胜期间会被消费，不在恢复后重放。

原生控件保留浏览器组合键行为，没有抢占 Ctrl/Meta/Alt 的自定义键盘处理。取消按钮保持稳定 DOM 身份。控件因为暂停、成功或换关不可继续使用时，若焦点在模块内，移至稳定模块容器；外壳控件上的焦点不被抢走。所有核心控件至少 44px，悬停、按下、禁用与焦点样式显式定义。

光路和波形均使用固定尺寸、可键盘聚焦的横向滚动视口，避免小屏把 SVG 文字缩小。光源、目标、输出、库存、相位和谐波系数都有完整可见文字；通关不依赖辨色。曲线目标使用虚线，当前使用实线。

## 验证范围

`tests/lightWaveGames.test.tsx` 包含：

- 独立 BigInt 光学计算与反向库存枚举，覆盖所有 12 个滤光证书和可替代解。
- 独立的 64 点余弦直接求值及离散傅里叶分析；最大谐波为 4，64 点足够避免该模型内混叠。
- 所有频率、振幅、四分之一圈相位的独立换算检查，以及与生产搜索不同顺序的资源剪枝求解。
- 24 条完整的 jsdom 控件通关流程，使用独立求解结果，验证成功不可撤销、重置与回调次数。
- 非法操作、成本与库存、证书副本和破坏、替代解、搜索预算/取消、实际局面提示、暂停 token 消费、定时器清理、StrictMode 和内外部焦点覆盖。另独立穷举 ws-11 的所有可行设置，验证任何合法解都必须包含相消。

jsdom 验证不等于真实浏览器、真实手机或完整无障碍认证。发布前还应在注册入口完成桌面与移动 Chromium 的操作、截图和布局检查。
