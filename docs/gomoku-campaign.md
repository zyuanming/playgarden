# 自由五子棋：完整对弈与棋形练习

## 产品边界

本模块是一款游戏。双人、电脑和练习是模式，不重复计数。新增 24 道固定原创练习，因此目录为 84 款、2052 关；自由对局的随机走法和电脑档位不计入关卡总数。

15×15，黑先，任意空交叉点落子。横、竖、两个斜轴连续至少五子获胜，长连同样获胜，无三三/四四禁手。满盘先判获胜再判和棋。明确是自由五子棋，不宣称标准五子棋、Swap2 或连珠竞赛支持。

## 来源与隐私

实际将 `tombelieber/gomoku` 固定提交 `0d8f81e687a04c729b1dfe5b0ce028295528cc17` 的 `board.rs`、`eval.rs`、`ai.rs` 改编为 TypeScript。静态阅读后移植，没有执行上游 Rust/build/WASM。原始文件、字节哈希、固定链接、MIT 全文在 `vendor/open-gomoku/`；构建直接分发 `public/gomoku-LICENSE.txt`，外壳显示作者、固定版本与许可链接。逐函数改编映射见 `gomoku/port-provenance.md`。

不引入上游 web 壳、依赖、Cloudflare 统计、Google Fonts、音视频、标志或 PWA。原创 DOM/CSS/SVG 图形、教学文字和题库；使用站点原有系统字体。没有帐号、聊天、排行榜、付费、个人数据或局面上传。电脑 Worker 与全部资源使用同源静态文件。没有新增 npm 依赖。

## 对弈

- 本机两人轮流下，或选择黑/白对电脑。
- 电脑仅为入门陪练：轻松最多一层，认真迭代至三层，限制搜索节点与耗时；没有 Elo、必胜或低端设备时延承诺。
- 每个搜索节点截断启发式候选前先完整扫描一步胜/挡五。迭代未完成时保留上次完整答案，绝不占已落点。
- 搜索在独立 module Worker。UI 延迟 260ms 再起任务，使状态先可见。节点/时间合作截止之外，还有 1800ms 外部看门狗。
- Worker 不可用、失败或超时：终止 Worker，用有界的成五/挡五/邻近简易规则返回合法点，并显示“简易兼容陪练”。不把回退宣传成相同棋力。
- requestId + 完整棋谱签名 + 组件存活标记 + 暂停检查。重来、悔棋、改设置开新局、后台隐藏、暂停、换模式、离开都会真正 terminate 搜索，过期回复也无法落子。
- 双人悔一手；电脑悔到你最近一次决定之前，包含随后电脑回应。你执白时保留电脑最初黑子。已结束自由对局可明确悔棋复盘，终局后的普通落子一律拒绝。

## 交互与保存

- 触控/鼠标只预览空点，必须按大按钮“确认落子”；重按不会重复落子。非重叠真实15路交叉点，未虚称每个格子达到44px。
- 单一 Tab 入口与 roving focus；方向键、Home/End 移动，Enter/空格落子；Ctrl/Meta/Alt 组合键与重复落子 keydown 不处理。Esc 暂停忽略 repeat，避免长按取消暂停。
- 坐标 A1–O15、黑/白文字、最后落子圆点、成五星标与整条多轴连线，信息不只靠颜色。
- 原生选择器与确认控件最小44px；320/390/1536宽布局纳入真实浏览器验收。减少动画偏好无动画；不依赖声音。
- 版本化自由规则 ID、玩法/颜色/难度、完整已提交棋谱、练习 ID。恢复严格重播黑先交替、边界、非重复、终局后不可续着；练习还校验初始历史前缀与中途电脑的确定防守。不会信任本地“已胜”标记。
- 坏存档从可解释初始盘重开；存储拒绝/容量满有明确提示，仍能游玩。自由对弈与练习使用不同存档。模式选择可恢复，练习完成才计入大厅进度。
- 设置先选择再明确“按设置开新局”；有进行中棋谱时再确认一次，避免无意结束。重选当前模式没有副作用。

## 四章教学

每章6题。首章学习边缘、竖线断点、两种斜线、自由长连与交叉成五。第二章学习各种迫切防守。第三章主动构造多个成五点。第四章在唯一迫切防守点上同时进攻，然后实际走完对手防守与自己的成五。

第三章双威胁与第四章两手必胜的第一手数学条件相同：自己未直接成五、对手没有一步胜、自己至少两个不同一步成五点。二者不是两套不同规则。第四章额外有初始唯一对方威胁，且必须下完三步；第三章在构造完成时结束练习。

`gomoku/corpus.json` 是完整原创题库，`certificates.json` 是12题、2557个全部合法对手回应证明。前端只懒加载精简题面，通用目标判定不硬比较作者给出的首手。活三题的两个正确首手均通过。24题除全盘D4/换色去重外，还移除补手棋子后做平移/D4/换色局部形去重，避免远处随机棋子掩盖同题。
