# 星星布阵

- ID: `star-battle`
- 原创实现、10 份原创区域划分、中文教学、CSS 与 SVG 插图，许可证均为 GPL-3.0-only。未复制第三方代码、关卡或素材；星星布阵是一类经典约束谜题。
- 每关包含 5–8 行/列与同数量的正交连通区域。每行、每列、每区域恰好一颗星星；星星不能八方向相邻。叉号为可选笔记。
- 每份关卡有独立区域形状、教学目标和合法完整解法见证；不是通过旋转同一关卡扩充数量。不宣称唯一解，任何符合规则的完整安排都会获胜。
- 数据与规则：`src/games/starBattleLogic.ts`，导出 `starBattleLevels`，每关的 `solution` 是按行排序的格子索引。
- 规则层检查索引与标记合法性；完整胜利后规则层及界面均锁定。重来或换关开启新一轮。撤销恢复最后一次星星或叉号编辑。
- 当前局面提示先检查直接冲突，再按已有星星和叉号进行最少候选行优先的确定性回溯。上限为 100,000 个节点；达到上限会明确说明，不把超时当无解。提示只建议，不自动落子。
- 区域同时使用粗边线、字母和柔和底色表达；星星数、区域计数和文本错误说明均可读。所有操作可由按钮、Tab、Enter、空格完成。
- E2E：`e2e/star-battle.spec.ts`。单次定向调用由集成方运行，同时覆盖 desktop/mobile：首关与末关真实点击完成、独立终局规则断言、键盘/触摸、叉号、当前状态提示、暂停恢复、撤销、重来、完成态锁定、控制台错误、横向溢出和开始/中途/完成截图。作者未运行浏览器或单元测试。
