# 词链拼接

每张牌是一个方向固定的双字词。把当前字与下一张牌的首字接上，其末字成为新的当前字。只按简体字字形匹配，不按读音；例如“头发 → 发芽”的“发”虽然读音不同，仍然可以接。每张牌只能用一次，编号印章从小到大接入，中间可以接普通牌。全部词牌用完且末字到达终点，才算过关。

100 道原创关卡，保留前 12 关和已有存档。从三张词牌入门到十六张牌的印章路线。第 2 关一开始就能接到终点字，但还剩五张牌；第 7 关即使字对上，也可能盖章太早；第 12 关共有三条合法路线。提示只标出当前有完整后续的词牌，撤销会还原当前字和待盖印章。浏览器仅保存已接的词，恢复时逐一重放合法接法。

第 13–34 关练习岔路和回环，第 35–56 关有两枚顺序印章，第 57–78 关有三枚，第 79–100 关有四枚，棋盘至多十六张牌。第 100 关开头三张就能回到终点字“水”，但还有十三张牌，必须继续沿正确的印章顺序接下去。

玩法、词牌数据及 SVG 封面均为 GPL-3.0-only 原创，不使用外部词典、图库或新依赖。验收：`npm run test:e2e -- e2e/word-chain.spec.ts`。
