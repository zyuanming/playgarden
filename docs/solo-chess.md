# 棋子独奏

- ID：`solo-chess`。10 个有限关卡，使用 4×4 / 5×5 棋盘，3–9 枚混合棋子。
- 原创 GPL-3.0-only 规则代码、关卡、中文界面、CSS 与程序化 SVG 美术；未复制第三方源码、题库或素材。采用经典国际象棋棋子运动几何，但这是一人吃子消除谜题，不是双方棋局，也不是骑士巡游。
- 全部棋子属于同一道谜题，无颜色阵营、将军、易位或兵。每回合选择一枚棋子吃掉另一枚，落子后保留吃子者种类。禁止走向空格；恰好剩一枚任意棋子时获胜。
- 车沿直线、象沿对角线，都被中间棋子阻挡；马走 2+1，可越子；王八方向走一格。规则层验证全部输入与几何，终局后禁止继续编辑及撤销。
- `src/games/soloChessLogic.ts` 导出 `soloChessLevels`，每关有 `solution: { fromCell, toCell }[]` 合法吃子见证。原创布局通过逆向吃子构造，提供不同棋子组合、通路阻挡、接力落点和顺序选择；不宣称唯一解或最优解。所有合法单子终局均接受。
- 当前状态提示使用有死局缓存的确定性深度优先搜索，最多 60,000 个节点。搜索到上限与确实无解分开反馈。提示仅选中来源和标出目标，不代替玩家操作。
- 重来和换关创建新局；暂停冻结选择和吃子；撤销恢复整次吃子前的棋盘；真实完成后完全锁定。无需计时，不运行后台动画或联网服务。
- 字形、中文棋子名、坐标、选中状态、目标圈和文字说明共同表达状态，不只依赖颜色。按钮支持点击、触摸、Tab、Enter 和空格。
- `e2e/solo-chess.spec.ts` 由集成方运行一次定向调用，覆盖 desktop/mobile 首末关真实吃子完成，逐步独立检查运动几何、直线阻挡、移动后保留种类和棋子数；并覆盖非法空格操作、非法几何、暂停恢复、撤销、重来、当前局面提示、终局锁定、点击尺寸、横向溢出、错误捕获与开始/中途/完成截图。作者未运行 E2E 或单元测试。
