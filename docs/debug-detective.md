# 调试侦探

玩具灯光程序有一行需要修正。三位输入 ABC 读作 000–111；各行依序读取当前值并写回一个开关，最后用指定的两位作为灯输出。一次测试记录同一输入的期望值、故障输出和可展开的执行轨迹。即使两种输出相同，也能排除会把该行为改坏的方案。

每关可用一到三次测试，重复输入不计入。只有证据留下唯一方案、玩家选中它、且它通过全部八个输入时才算修复。可撤销最后一次测试并拿回次数；预览只计算已测试过的输入，提示用候选方案的预测分组估计最坏还需要几次测试，不偷看尚未公开的期望结果。

12 道原创关卡及规则实现、SVG 均为 GPL-3.0-only，无外部依赖。参考解法只供浏览器验收。第 12 关可演示一个会浪费线索的开局；撤销后可以改选更能区分方案的输入。按关卡保存输入、证据及方案选择，支持刷新后继续。测试命令：`npm run test:e2e -- e2e/debug-detective.spec.ts`。
