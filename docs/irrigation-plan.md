# 灌溉规划

12 道原创谜题。每个阀门是关闭、窄喷或宽喷；喷洒模式给覆盖的每块田一单位水。重复覆盖相加，田块必须恰好达到目标，不是至少达到。耗水从阀门所属水箱计入；多个水箱不能共享预算。允许未达标或超额的草稿，以便回头修改。

第 1–5 关使用一个水箱并逐步增加重叠；第 6–12 关使用两个独立水箱。关闭任何阀门都必须是可撤销的操作。提示检查最多 2,187 种组合，选当前草稿需要修改阀数最少的有效方案，建议改一个阀而不代替玩家执行。只保存已完成关卡，不保存草稿。

界面、源码、谜题与程序化美术均为 GPL-3.0-only 原创，不依赖新软件包或外部资源。操作验收：`npm run test:e2e -- e2e/irrigation-plan.spec.ts`。
