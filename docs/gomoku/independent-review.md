## 目标语义和接入要求

完整格式与定义在 `oracle-contract.md`。关键点：

1. `win`：本手连续至少五子。六子及更长一样获胜，两色对称。
2. `defend`：初始对方存在立即获胜点；本手必须不终局，并消除对方全部立即获胜点。只挡住一个开放四子的某一端不能过关。题库保证玩家初始没有立即获胜点。
3. `fork`：本手不终局，对方没有立即获胜点，玩家至少有两个不同立即获胜点。本章从没有对方即时威胁的局面开始。
4. `two`：本手不终局，对手无论怎样合法应对，玩家都能在下一手立即获胜。每题初始都存在对手的唯一成五点，所以玩家必须兼顾防守和构造双威胁。应实际执行玩家、对手、玩家共三手。

`fork` 与 `two` 的首手数学性质相同。两章的真正教学区别是局面与操作：主动构造并识别双威胁，以及被迫防守时找到反击并亲自完成第二手。没有把等价性质包装成两种规则。

`continuation` 是从题面起的完整示例着法，第一项就是 `solution`。对方示例防守堵住当前玩家成五点的最低索引；所有其他合法防守也已覆盖。`fork` 可以首手即完成练习，后两手供解释；`two` 只有第二手真的成五才能完成练习。

## 24 题的教学差异

### 第一章：这一手连成五子

1. 棋盘上沿的连续四子，认识边界。
2. 竖向两段之间的内部空位。
3. 一端被挡住的主斜线断点。
4. 左下角反斜线的内部断点。
5. 三子与两子合成六子，直接验证自由长连规则。
6. 横竖同时成五，认识共享落点。

### 第二章：先守住对方的成五点

1. 一端已有阻挡的冲四。
2. 两段二子之间的内部威胁。
3. 两段三子之间可形成七子的威胁。
4. 横向与斜向共用同一个必须防守点。
5. 一端受棋盘边界限制的斜向冲四。
6. 自己已有可发展三子时仍应先防对方的三加一断四。

### 第三章：准备至少两个机会

1. 连续三子伸成活四，两端均为正确第一手。
2. 补跳三内部空位形成活四。
3. 两端被挡的横、竖三子共同形成双冲四。
4. 补横线空位的同时延伸斜线，形成跨方向双威胁。
5. 两条线下一手需要补的都是内部空位，形成双断四。
6. 横、竖、斜三条线同时形成机会，验证自由规则没有双四禁手。

### 第四章：挡住这一手，再完成下一手

1. 挡竖向冲四，同时把横线伸成活四。
2. 对方竖线的必须防守点同时补好己方跳三。
3. 换白棋行动，挡横线同时延伸斜线。
4. 挡竖线，同时形成横向和反斜向双冲四。
5. 挡斜线，同时留下两个不同的内部成五点。
6. 挡反斜线，同时构造直连、断点和斜连的三向机会。

24 题均有至少两个合法非解落点，不存在所有空点都通过的退化题。

## 去重与历史有效性

- 全棋盘去重：八种旋转/镜像，并允许颜色互换，24 题没有重复。
- 更强的局部结构去重：先去除仅用于补足交替手数的远处棋子，再按平移、八种旋转/镜像和颜色互换规范化；24 题仍没有重复。因此没有用随机远处棋子掩盖同形复制。
- 所有补足手数的棋子离教学棋子及推荐落点至少三个切比雪夫格，并且不得增加任何初始立即成五点。
- 所有历史完整重播，任何前缀出现终局后都不得继续。第四章每题初始恰好只有一个对方立即获胜点，且它就是正确首手。

## 独立裁判与规则覆盖

`oracle.py` 以全部 572 个五格窗口为判定基础，天然把至少五子与长连视为获胜，与常见的落子后射线计数实现结构独立。立即成五点通过枚举每个含四颗己子和一格空点的五格窗口取得，无候选截断。最大获胜连线另用首点扫描，支持交叉多线与长连长度核对。

测试覆盖：

- 四轴、两色、四子不胜、五子胜、六/七/十五子胜。
- 四角与棋盘四边，不允许扁平索引跨行接起来。
- 中间空格、对方棋子切断、开放四子的两端。
- 填内部空位形成六/七子，合法交替历史下两色六子都胜。
- 同一手形成横、竖、斜三条获胜线。
- 黑棋双威胁可合法落子，无禁手。
- 黑先轮换、不可变旧状态、叠子/负值/越界/小数/字符串/布尔值拒绝且不吃回合。
- 终局后拒绝继续，逐前缀重播与任意步数悔棋恢复。
- 100 盘固定种子的完整随机合法对局及重播。
- 真正满盘和棋：颜色公式按 `(row + 2*col) mod 4` 的两组余数分配，黑 113 白 112，四个轴上的同色连续段均不超过 2。
- 满盘最后一手成五，先判胜后判和，并验证此前 224 手没有终局。
- 目标反例：仅挡开放四子一端不算防守成功；直接成五不算 defend/fork/two；忽视对手立即获胜点的“假双威胁”不通过。
- 全部题目的全部正确首手与完整应手证书，以及每一个终结着法。
