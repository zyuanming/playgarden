# 周长花园

原创的面积、周长与连通性游戏，共 8 个手工设计关卡。

## 规则

- 点击空地种花，再次点击可移除。编辑次数不限，过程中允许暂时超出目标或分成多片。
- 星星是预先种好的固定花格，不能移除，并计入面积；标有 × 的石板不能种花。
- 面积等于全部花格的数量，必须恰好达到关卡目标。
- 周长等于花格所有外露边的数量：`4 × 面积 − 2 × 共享边数`。棋盘边缘、石板边缘和花圃空洞的内圈边界全部计入。棋盘上的金色 SVG 线逐段显示这些边。
- 所有花格必须通过上下左右共享边连成一片。仅在角上接触不算连通。

胜利判定接受每一个满足面积、周长、四邻连通、固定花格和石板约束的布局，不与预设示例比较，也不要求唯一答案。例如第一关的 `[0,1,4,5]` 与示例 `[5,6,9,10]` 都是有效的四格正方形（索引从左上角 0 开始，逐行递增）。

## 操作

- 鼠标点击或触摸花格可种花、移除；格子使用至少 44 像素的原生按钮。
- 键盘用 Tab 移动焦点，用 Enter 或空格激活。
- 暂停保留棋盘并阻止编辑；继续后恢复操作。
- 撤销退回一次编辑；重来仅保留固定星星。
- 提示指出朝向一种预设可行布局的一处改动，不自动编辑，也不保证是当前方案的最短改法。它可能建议移除属于另一种有效方案的花格，界面会明确说明提示只是一个参考方案。
- 完成后锁定棋盘；撤销和提示都不会覆盖已完成的其他有效布局。重来可以重新开始。

## 实现与验证范围

关卡位于 `src/games/perimeterGardenLevels.ts`，组件位于 `src/games/PerimeterGarden.tsx`。提示才读取示例布局；完成判定独立计算面积、共享边、连通分量及固定/禁止格约束。

`e2e/perimeter-garden.spec.ts` 是一条供桌面与触摸项目运行的首关/末关操作旅程，覆盖非示例首关解、暂停、撤销、提示不改棋盘、重来、完成锁定、44 像素目标、溢出检查及截图。它通过真实格子操作后独立计算面积、外露边和连通性，并检查末关庭院的四条内边。该 E2E 已编写，尚未运行。TypeScript 类型检查和 GPL/运行时许可告示检查已通过；未运行单元测试或关卡穷举。
