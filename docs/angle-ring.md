# 角度拼环

100 道原创关卡。每个拼环从 0° 开始，按顺时针依次放固定扇片。扇片不能翻面；前后接缝符号要相同，目标角度要刚好拼满，终点也有指定符号。有定位钉的盘面必须在该角度留下指定符号的接缝，不能越过。多个拼环共享同一套扇片，全部拼满且用完全部扇片才结束。

第 1 关只看角度和接缝，第 2–4 关加入定位钉，第 5–7 关加入共享库存，第 8–12 关把规则组合起来。其后从单环接缝练习，推进到多定位钉与共享扇片；末章需要同时给三个拼环保留合适的扇片。第 66、72、78 关各有两种合法布局。前 12 关与已完成记录不变。图形、玩法实现与关卡均为本项目原创，GPL-3.0-only；不依赖外部图像、网络请求或新软件包。

键盘按数字键放对应扇片，左右方向键换拼环，触屏点相应按钮。当前局面搜索有 4,000 节点上限，找不到解与未能在预算内取得结果分别提示，不自动放扇片。已完成关卡由游戏大厅保存在本浏览器，半局不保存。

关卡数据与每关合法解法见 `src/games/angleRingLogic.ts`。定向验收：`npm run test:e2e -- e2e/angle-ring.spec.ts`。
