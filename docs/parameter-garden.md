# 参数花园

同一套配方作用于本关所有印盘，但每盘有自己的原始印章、锚点和目标。绕印章原点顺时针旋转；第一印位于锚点；后续每印都相对于上一印移动指定距离。重叠只算一格，越界剪去而不绕回。预览用坐标、符号和颜色标记吻合、缺印、额外印迹。

12 道原创谜题。草稿不记步，只在点击“应用配方”时提交。撤销恢复上次应用前的共享配方；切盘与提示不改参数。所有盘同时匹配并提交才通关。最后一关任意选两盘都还不够，第三盘会排除另一个似乎正确的配方。完成记录由游戏大厅保存，未完成草稿不跨刷新保存。

键盘 R/D/C 改变旋转/位移/次数，[ 或 ] 换盘、A 应用，也可用普通焦点键操作按钮。程序、关卡和图形均为 GPL-3.0-only 原创。无新依赖。验收：`npm run test:e2e -- e2e/parameter-garden.spec.ts`。
