# 星门守望 · Star Sentry

星门守望是原创的固定视野编队射击游戏：飞船只横向移动，主动发射向上光束，解除移动机器人；机器人的反击需要躲避，浅蓝掩体会消耗耐久并阻挡双方弹道。三个护盾用完则本轮结束，可无限次重试。清空本关所有机器人且仍有护盾才报告成功。

它与反弹砖园的挡板反弹、云迹跑者的跑跳、月面着陆的重力/燃料控制不同。这里没有反弹球、跑跳或惯性着陆，也不把换皮或参数变化单独计为新游戏。

关卡数据在 starSentryLogic.ts 中显式列出，无随机生成、无无尽模式、无隐藏增援、无必须等待的倒计时和无底部入侵时限。敌方光束向预告时的旧横坐标发射，不在飞行中追踪；初关没有掩体且反击缓慢。

## 输入、暂停和进度

- 必须按「开始守望」后才会运行；开始后可自行开启自动射击，默认关闭。
- 左右方向键 / A、D 横移，空格 / 上方向键 / W 发射；三个大按钮支持按住和多点触摸。按钮聚焦时可用空格或 Enter 按住。
- 松开、取消触摸、失去捕获、失去键盘焦点、重来、换关、卸载都会清理相应输入；Ctrl、Meta、Alt 组合键不被游戏接管。
- 外壳暂停、窗口失焦、隐藏页面会冻结仿真并关掉自动射击；返回后须显式恢复，不补算暂停时间。
- 仿真单帧最多推进 50ms，每个子步最多 1/120 秒，活动弹丸上限 36。固定机器人/掩体数量；终局清空弹丸，停止帧循环。
- 通关只从真实命中与剩余护盾计算，终局每轮只报告一次。没有「通关」按钮、测试注入接口或解法播放。
- 外壳通过 resumeKey 保存当前关卡并保存完成记录。本模块不保存飞行中的位置、伤害或弹丸；重新进入从准备状态安全重开，同样在界面明示。不要将这种行为称为中途续飞。
- 不支持实时撤销，注册需设置 allowUndo: false。
