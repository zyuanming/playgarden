# 空间装箱

三个轴可做刚体旋转，不可镜像。任选剩余积木和俯视锚格，积木从箱口固定朝向直落。任何部分超高或出界都会挡下整件。搭桥本身合法，但留下的竖直封口永远无法填补。必须用完所有积木、填满所有格才过关。接受所有合法装箱顺序。

12 道原创题从 2×2×2 到 3×3×3。第 12 关有可达的六件装箱，但也存在不能直落重现的静态拼合：其中两件互相要求先落。提示从当前格子和剩余件搜索，最多检查 150,000 次候选落点；达到上限与已证无解分别提示。封住的竖直空格可立即证明无解。预览、分层查看和提示不改变已落积木。存档保存实际操作，加载时重放合法投放。

原创关卡、SVG 等轴侧立方体、程序和封面均为 GPL-3.0-only，无图形引擎或外部模型。关卡证书只用于浏览器验证。测试命令：`npm run test:e2e -- e2e/voxel-packing.spec.ts`。
