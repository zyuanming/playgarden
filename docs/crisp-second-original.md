# PIZZA ARROW、RPS、SWINGBY 完整原作适配

本包新增三个原作目录和中文外层说明，不单独复制、变更或分叉共享运行时。三款都是完整无尽游戏，各有 0 个有限关卡。未登记到目录，未计入上线数量。原脚本保留固定提交 `cfb39d2f988feb5918eb83697145b5a35adabf58` 的每个字节，包括 CRLF。

## 披萨神箭 · PIZZA ARROW

按住拉弓减慢旋转，松开射出，拉满也会自动发射。黄色碰撞会消耗箭，但只有命中相位严格位于剩余扇区内时才切下一块；黄色擦边可能没有切块和得分。切去两侧中较小的部分，分数为 `ceil(切去弧度 ×100×当时倍率)`，随后增加倍率。每盘箭用完后下一盘的箭数递增，倍率归 1。红色内弧碰撞结束，原自动重开与操作回放保留。没有修正或美化这些原始碰撞、自动发射、残片或难度规则。

## 猜拳四轨 · RPS

每个有效按下边沿同时向右换一轨并循环换一种手势；4 轨 ×3 手势形成完整 12 步循环。克制对手获得当时倍率分，然后倍率增加；同手势顶回敌手且不重置倍率；落败重置倍率并冻结输入。长按不连续换道，冻结时点按无效。队列持续生成、挤压并下降；任何敌手越过底部 `y > 99` 才结束，单次猜输并不结束。

## 引力远航 · SWINGBY

按住施加与当前速度方向垂直的右侧推力，松开仍继续飞行并受原简化引力、阻尼及前推影响。星体按照原间距和范围规则生成、移除。分数保持原作的 `floor(ship.pos.length)`，即离起点的直线距离，会减少；不累加每帧距离，不锁为本局峰值。实际碰撞每帧加 `4×difficulty` 损伤，无碰撞且还有损伤时每帧减 `difficulty`，累计超过 99 才失败。星体绘制和碰撞本身为有厚度的圆环，进入内部可能恢复；不把它改成实心球或碰一下就输。

SWINGBY 使用原 `dark` 主题。原引擎明确让 `simple`、`dark` 都使用 Canvas 2D；本包附最小共享补丁，将已有适配的 simple-only 拒绝条件扩展为只允许这两个主题。其余 Pixi/capture/rewind/minifier 限制保持。

## 观察器与本机纪录

每款 `observe.js` 包装现有 `update`、`play`、`addScore` 调用边界，仅收集事件和复制可读状态；每个原函数按原参数、原 `this` 调用一次。没有写飞船、星体、披萨、手势、分数、时间、输入或难度，没有可写测试后门。统计按真实 run ID 清零并排除自动回放事件。

继续依赖唯一共享生命周期：静音 master gain、暂停模拟和 AudioContext、真实 Pointer Events、取消输入、退出销毁监听/RAF/context。沿用原引擎回放。最高分只由真实结束的对局最终分数更新；SWINGBY 曾经飞过的最远位置不会被偷偷当作最终得分。

三个定向 E2E 均使用物理鼠标/键盘或 Chromium CDP 真触摸通道，基于只读状态反馈操作，不注入游戏状态。共享 helper 在脚本加载前把普通 `Math.random` 固定到种子 83173，仅用于可重复场景；原游戏的选项种子与难度不变。PIZZA 的射击预测仅做测试操作时机计算；RPS 在 12 步循环内选择目标；SWINGBY 用真实星体位置指引右转，无法仅靠静态检查证明控制器在手机/桌面都收敛，必须由定向 CI 建立证据。

待整合者分别运行 `e2e/pizzaarrow.spec.ts`、`e2e/rps.spec.ts`、`e2e/swingby.spec.ts` 的桌面/手机流程并检查真实截图。任何失败只修复相关流程，不能改低原作难度、注入状态或删除关键断言来通关。
