# Classic 2048

The stable game ID remains `merge`, preserving favorites and last-played identity. The title is `2048`. This is one endless score game with zero finite levels; the former twelve authored teaching levels and routes are removed. The catalog has 86 games and 2059 finite levels. No level picker, completion badge, next-level action, or fabricated win percentage is shown for this game. Historical completed indices are ignored by its card and continue ordering; they do not become score records.

An effective move compacts one direction, merges equal neighbors once per source, awards the resulting merged values, and spawns one 2 or 4. A no-op changes neither board, score, move counter nor PRNG seed. Forming 2048 does not stop play. A round ends only when no direction changes the board. A random starting seed gives each new game a new board; the saved seed makes undo/replay deterministic. The last 32 moves are retained, keeping an endless game bounded in memory.

`playgarden.merge.v1.round.free` holds a versioned current board/score/move count/seed and bounded undo history. `playgarden.merge.v1.best` holds the independent best score. Restart and undo never lower the best record. Invalid saves safely start a fresh round; storage failure is disclosed while play remains usable. The former teaching implementation did not save board state or numerical scores, so there is no invented score migration.

Every tile has a stable identity. A move retains and animates all source tiles, including both sides of a merge, through a 150 ms translation to the target square. Only then do the resulting value and newly spawned tile appear, with separate 230 ms merge-pop and 180 ms spawn effects. Input is queued in order; after a short 110 ms settlement, the next move begins without waiting for decorative effects. Pause, visibility loss, undo, reset and unmount cancel visual work and queued input while preserving the already accepted board. Reduced-motion mode uses the identical rules without animation delays. Keyboard handling is scoped to the board and preserves browser modifiers; pointer cancellation does not create a move.

Verification includes an independent cell-by-cell oracle, exhaustive lane cases, seeded boards, stable identity and merge-source checks, save/reset/undo tests, and real-browser movement-midpoint and merge-pop frame measurements. Development checkpoints are not release certification. Final exact-commit CI and public-site evidence are required before merging to main.
