# 磁场迷宫

小车只会沿直线滑行。先选与小车同一行或同一列、且中间没有墙或另一块磁铁的固定磁铁。标记同极时远离磁铁，异极时靠近磁铁，都会停在第一处障碍或边界前。翻转台只在小车停稳后可用；换极是玩家主动选择的一个动作。只有停在出口才算完成。

共 12 道原创关卡。第 4 关用同一块磁铁对比推与拉，第 5 关展示滑过出口并不算到达，第 11 关允许不同的磁铁产生同一落点。界面用 N/S 字母、箭头和落点框预览结果。提示从当前位置与极性寻找最短路线，不自动操作；撤销恢复位置和磁极；本机存档按关卡重放已确认的动作，不记录预览。

这是用磁极概念解释规则的离散玩具模型，不是真实力学仿真。程序、关卡与封面均为 GPL-3.0-only 原创，不新增依赖。验收：`npm run test:e2e -- e2e/magnetic-maze.spec.ts`。
