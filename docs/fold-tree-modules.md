# 折纸打孔与树形旋转

这两个独立游戏模块及其关卡、样式、程序化图形和测试均为原创 MIT 代码。没有移植第三方关卡、素材、字体或模型；纸层预览使用项目已有的 Three.js。

## PaperFold · 折纸打孔（12 关）

每个原格有固定的行列身份。折痕位于相邻格中心之间，只能使用公开列出的方向。移动的整个纸叠反射到另一侧，层次倒序并落到静止纸叠之上。打孔会贯穿当前位置的每个原格；展开后必须刚好匹配公开目标，所有未标记的原格保持完整。

关卡依次引入一次反射、偏心折痕、四层交点、厚薄区域、二次翻叠、六孔组合、八层孔、留白边缘、三层风琴、上下短折、十孔逆推及十二孔综合。尺寸最大 6×6，折叠至多 3 次，打孔至多 2 次，公开折痕至多 4 个。至少折一次才允许打孔；第一次打孔后禁止继续折叠。预算都是上限，不要求用满。

- `paperFoldLogic.ts`：独立规则、校验、不可变历史与 BFS。
- `paperFoldLevels.ts`：12 组公开目标及教学文本；目标是直接写出的原格编号列表，不会从证书计算。
- `PaperFold.tsx` / `paperFold.css`：原格坐标、允许折痕、目标图和完整文字列表始终可查。实际打孔区与目标图各自显示，数字层数和原格清单不依赖颜色。
- `PaperFoldScene.tsx`：按需打开静态 Three.js 纸层预览。每个原格对应薄盒，打孔格由四个纸条盒表现贯穿方孔；图形来自当前真实叠层。无动画循环；暂停/后台不渲染，卸载释放几何体、材质、观察器和渲染器；WebGL 不可用或上下文丢失时继续使用完整 2D/文字操作。

搜索从当前真实映射开始，保留折数、孔数、孔位和阶段。错误孔不可恢复，因此安全剪去已多打孔的分支。最多允许 60,000 个不同状态，支持取消；到达上限或取消只报告暂时没有可靠建议。只有搜索完成才能报告无解。序列深度最多 6（3 折 + 2 孔 + 展开），粗略未去重的合法前缀树不超过 `85 × (1 + 36 + 36×35) × 2 = 220,490` 个节点；去重、实际空格和目标剪枝显著缩小关卡搜索。所有当前关卡初始搜索均在 600 个状态内。

证书：`certificate.actions`，元素为 `{kind:'fold', crease:'A'}`、`{kind:'punch', cell:编号}` 或 `{kind:'unfold'}`。编号从 0 开始，按行排列。证书仅供离线验收，不参与运行时目标、搜索或提示。

DOM 选择器：`[data-paper-fold-game]`、`[data-paper-won="true"]`、`[data-paper-fold="A"]`、`[data-paper-cell="编号"]`、`[data-paper-unfold]`、`[data-paper-undo]`、`[data-paper-preview]`。`data-paper-state` 与格子的 `data-paper-layers` 可供验收比对。

## TreeRotations · 树形旋转（12 关）

使用二叉搜索树的合法左、右旋转。选中节点后左旋使其右孩子上升，右旋使左孩子上升；内侧子树移交给下降的旧父节点。固定键值的中序顺序始终不变。公开目标包含树高、逐节点平衡、指定树根，以及后段的加权搜索成本。根深度为 1，成本为全部“权重 × 深度”之和。任何满足全部目标的形状都可通关。

12 关依次教学单旋、双旋、指定根、局部平衡、内侧子树转交、多解规划、六键整形、深处调整、七键树冠、单热点、双热点以及平衡与成本权衡。

- `treeRotationsLogic.ts`：不可变指针树、合法旋转、校验、成本与平衡判断、BFS 最短续解。
- `treeRotationsLevels.ts`：独立公开目标、权重及解法证书。
- `TreeRotations.tsx` / `treeRotations.css`：按键值固定横坐标、深度固定纵坐标的图。每条边只连接相邻深度，端点缩短到节点框之外，不穿过其他节点。父子关系、深度和每项成本均有持久文字清单。

每关 3–7 个节点。同一有序键集至多有 Catalan(7)=429 个树形。BFS 去重所有形状，最多每形状尝试 14 个旋转（其中只有 n−1 个有效），不会重复搜索无限历史；支持明确的限额与取消结果。目标和提示完全独立于证书。

证书：`certificate.moves`，每步 `{key:键值, direction:'left'|'right'}`；`certificate.shortest` 是从初始树形到任意公开合格目标的最少旋转次数。

DOM 选择器：`[data-tree-rotations-game]`、`[data-tree-rotations-won="true"]`、`[data-tree-node="键值"]`、`[data-tree-rotate="left"]`、`[data-tree-rotate="right"]`、`[data-tree-undo]`。`data-tree-shape` 给出当前规范树形。

## 中断、键盘与验收

两个模块均实现 GameProps：换关或 resetToken 开启新轮；完成仅上报一次；成功后所有局面编辑与撤销锁定；暂停和成功时消费 hint/undo token 而不延后重放。未成功的错误展开或旋转仍可撤销。按钮 DOM 身份稳定，使用 `aria-disabled` 配合规则层及事件层双重阻止，保持不可用或完成后的键盘焦点；外壳触发提示或撤销不会抢焦点。重来或换关移除旧棋盘时，仅把旧棋盘内的焦点移到持续存在的模块容器，并使用 preventScroll 避免页面跳动；外壳按钮焦点保持不动。没有自定义快捷键，Tab、Enter、空格使用原生语义，Ctrl/Meta/Alt 不被拦截。控件最小 44px，图形区域有可见横向滚动说明，减少动态模式也无需动画。

`tests/paperFold.test.tsx` 以逐原格三维整数坐标的独立 oracle 核对反射、叠层顺序、孔位和最短解。`tests/treeRotations.test.tsx` 以父指针向量 oracle 核对全部 429 个七键树形、每个合法旋转及逆操作。测试覆盖证书 getter 抛错隔离、不同解法、非法状态、搜索上限/取消、24 个真实 DOM 控件关卡旅程、失败后撤销、暂停 token、完成锁定、重来、换关和焦点。

`tests/paperFoldScene.test.tsx` 使用受控 Three.js mock 验证实际叠层与孔洞对应的网格数量、暂停/后台/恢复、展开扁平化、上下文丢失后停止渲染、初始化失败回退，以及几何体、全部材质、渲染器和 ResizeObserver 的释放。它不验证 GPU 像素。

jsdom 验证的是组件与 DOM 行为，不代表真实浏览器视觉、WebGL 或移动设备验收。真实桌面/窄屏浏览器截图和完整项目集成须单独运行。
