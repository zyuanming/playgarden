选中有金色边框、正在晃动的目标。点击食物或 HTML 可以查看标签。

用选择器点一道菜

CSS 选择器决定哪些 HTML 元素应用样式。例如 p 选中全部段落；plate 选中全部盘子。

在编辑区输入选择器，再按 Enter 或“运行选择器”。需要选中全部目标，并且不多选。等价的有效选择器也能过关。

观察标签的嵌套、class、id 和 for 属性。桌上的图形和下方 HTML 是同一份原作关卡数据。输入 1 到 32 的数字可跳关，跳关不会获得完成记录。
